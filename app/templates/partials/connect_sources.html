Set up automatic sync via iOS Shortcut

Two ways to automate this, trading off coverage against how hands-off it is. Both use the same token below.

Option A: Full export — every metric, manual trigger

iOS has no Shortcuts action that triggers a Health export directly — it only starts from inside the Health app itself. Set the Shortcut up once below, then each sync is: export from Health, share it to your Shortcut.

{% if apple_health_shortcut_qr %}
{{ apple_health_shortcut_qr | safe }}

On your phone, easier than typing: scan with the Camera app, tap the text preview, then Copy — it carries both the URL and the Authorization header in one block.

{% endif %}

One-time setup

  1. In the Shortcuts app: + → Add Action → Get Contents of URL → URL from above, Method POST, Headers as above, Request Body Form with a field named exactly export_file (Type: File) set to Shortcut Input (tap the field, choose Variable → Shortcut Input).
  2. Tap the Shortcut's settings (ⓘ icon) → turn on Show in Share Sheet → under Share Sheet Types, make sure Files is checked.
  3. Rename the Shortcut (e.g. "Sync to Athlytics") so it's easy to spot in the Share Sheet.

Each time you want to sync

  1. Open the Health app → tap your profile picture (top right) → scroll down → Export All Health Data → Export. This can take a few minutes for a large history.
  2. When the Share Sheet appears, choose your Shortcut (e.g. "Sync to Athlytics") — it uploads the export automatically.

The export itself is a manual, Health-app-only step — Shortcuts and Siri can't trigger it directly, that's an iOS limitation. Once you tap Export and share to your Shortcut, the upload happens without any further typing.

Option B: Scheduled multi-metric — fewer metrics, fully automatic

Pull specific metrics with Find Health Samples yourself and post them as a dictionary. More setup per metric, but it's a separate endpoint built to accept that — and unlike Option A, it can run on a schedule with nobody tapping anything.

{% if apple_health_metric_types %}

{% for mt in apple_health_metric_types %}{{ mt }}{% endfor %}

{% endif %}
  1. In the Shortcuts app: + → add a Dictionary action. Add one key per metric you want, using the exact names above (e.g. steps, resting_hr, sleep_duration).
  2. For each key: add Find Health Samples for that metric filtered to Today, then Calculate Statistics (Sum for cumulative metrics like steps, Average for point-in-time ones like heart rate) — set the result as that key's value in the Dictionary.
  3. Add Get Contents of URL → URL from above, Method POST, Headers as above, Request Body JSON with a field named readings set to your Dictionary variable.
  4. Rename the Shortcut, then add a personal Automation (Automation tab → + → Time of Day, daily) that runs it, with "Ask Before Running" turned off.

Only covers metrics you wire up this way — and each one is its own Find Health Samples chain. Unrecognized keys are skipped and reported back, not silently dropped, so a typo won't fail the whole sync.
